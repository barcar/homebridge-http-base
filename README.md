This module is designed to be used as dependency for http based homebridge plugins. It exposes clients for http and mqtt.

Supported Node.js major versions are 22, 24, and 26.

It's generally used for my `homebridge-http-*` plugins like:
* [homebridge-http-switch](https://github.com/homebridge-plugins/homebridge-http-switch)
* [homebridge-http-lightbulb](https://github.com/homebridge-plugins/homebridge-http-lightbulb)
* [homebridge-http-outlet](https://github.com/homebridge-plugins/homebridge-http-outlet)
* [homebridge-http-humidity-sensor](https://github.com/homebridge-plugins/homebridge-http-humidity-sensor)
* [homebridge-http-temperature-sensor](https://github.com/homebridge-plugins/homebridge-http-temperature-sensor)
